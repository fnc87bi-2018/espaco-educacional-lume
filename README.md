# Espaço Educacional Lume — site institucional

Projeto inicial estático, responsivo e pronto para publicação no Cloudflare Pages.

## Arquivos
- `index.html`: página institucional.
- `assets/`: recortes de fotografias e identidade visual extraídos do portfólio enviado.

## Publicação
1. Crie um repositório GitHub chamado `espaco-educacional-lume`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No Cloudflare Pages, conecte o repositório.
4. Para este site estático, use:
   - Framework preset: None
   - Build command: (vazio)
   - Build output directory: `/` (raiz do projeto)

## Observação importante
As fotografias de Melissa e Juliana foram recortadas diretamente da página 2 do portfólio, sem geração ou alteração de rostos. Antes da publicação, confirme a autorização de uso das imagens e valide os textos, valores e condições comerciais.
